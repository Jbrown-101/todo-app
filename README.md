# Simple To-do list App
To-Do List App
A clean and simple to-do list app built with HTML, CSS, and JavaScript. I made this to practice DOM manipulation and get more comfortable working with dynamic content in the browser.
You can add tasks, check them off when they're done, and delete them when you no longer need them. Everything is stored so your list stays intact between visits. The UI is fully responsive, so it works on phones and desktops without feeling cramped or broken.
Features


- Add new tasks with a single click or by pressing Enter
- Mark tasks as complete with a visual checkbox
- Delete tasks individually with the × button
- Responsive layout that adapts to any screen size


-Built with: HTML · CSS · JavaScript
